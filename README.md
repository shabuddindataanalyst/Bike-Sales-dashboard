🚴 Just built my first Excel Dashboard — Bike Sales Analysis!

As someone starting out in data analytics, I wanted to get hands-on with real data and build something end-to-end. Here's what I built:

📊 What's inside:
• Bar chart → Avg income of bike buyers vs. non-buyers by gender
• Line chart → How commute distance affects purchase decisions
• Pie chart → Customer age bracket breakdown (Adolescents lead at 67%!)
• Interactive slicers → Filter by Marital Status, Gender, Region & Education

🔍 Key insights:
• Male buyers earn significantly more on average (~$45K) than female buyers (~$35K)
• Most purchases happen among commuters traveling 5–10 miles
• Adolescents make up the majority of the customer base

This project taught me how to clean data, use PivotTables, build charts, and wire up interactive slicers — all in Excel.

If you're learning data analytics, I highly recommend starting with Excel dashboards before jumping to Power BI or Tableau. The fundamentals transfer directly.
